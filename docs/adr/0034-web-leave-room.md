# 0034. チャンネルを自分で退出する入口

- 状態: 採用
- 日付: 2026-09-19

## 背景

チャンネルからの退出は、API（`DELETE /rooms/{id}/members/{自分}`）もサーバーのログ（「退出しました」。ADR 0033）も
クライアントの後始末（`room.member_removed` の `reason: left`。ADR 0026）もそろっているのに、**画面に入口がなく、デザインにもなかった**。
ADR 0032 で足した入口の洗い出しからも漏れていた（そこで見ていたのは「他人を外す」側だった）。

オーナーと確認して、これまでと同じやり方（既存の部品とトークンのまま描いて `docs/ui/` に足す）で進めることにした。
決めることは、入口の置き場所と、退出したあとの見え方の 2 つ。

## 決定

- **入口はチャンネルの設定ダイアログのいちばん下**に置く。見出し「チャンネルを退出」、結果の説明、`danger-outline` の「退出する」。
  形はワークスペースの退出（`workspace/settings-as-member.png`）に合わせる。
- **参加していれば、ロールに関係なく出す**（authz の `CanLeaveRoom` と同じ）。member が開く読み取り専用の設定にも出す。
  参加していない public を開いたときと、DM（設定自体を開かない）には出さない。
- 押すと確認のダイアログ（`LeaveRoomDialog`）に替わる。キャンセルすると設定に戻る。
- **説明は公開範囲で分ける**。退出したあとに読めるかどうかが違うため（ADR 0011）。
  - 公開: 退出したあとも読める。投稿するにはもう一度参加する
  - 非公開: 読めなくなる。戻るにはメンバーに追加してもらう
- 退出したあとの画面は、**別の端末で退出したときと同じ**にする（ADR 0026 で決めたもの）。
  - 公開: その場に残り、参加していない状態（下に「参加する」）で読み続ける
  - 非公開: 「外されました」は出さず、ワークスペースの入口に戻る
- ストアの `leaveRoom` は、応答を待ってすぐに `reason: left` と同じ後始末をする。イベントも同じ端末に届くが、
  WS が切れているときに画面が残らないようにする（ワークスペースの退出 `removeMember` と同じ）。後始末は 2 回起きても結果が変わらない。

## 理由

- **設定ダイアログに置く理由**: ルームのヘッダーには設定とメンバーのボタンしかなく、退出のためだけに「…」のメニューを新設すると、
  中身が退出 1 つになる（ADR 0032 で設定をメニューに入れなかったのと同じ理由）。ワークスペースの退出も「設定のいちばん下」なので、場所の感覚がそろう。
- **説明を分ける理由**: 公開チャンネルは退出しても読めるので、非公開と同じ強さで警告すると誤解させる。逆に非公開は、
  最後のメンバーが抜けると誰も戻せなくなるほど重い操作なので、読めなくなることをはっきり書く。
- **退出後の画面を別端末と同じにする理由**: 自分で抜けたのに「外されました」を出すのはおかしい、という判断は ADR 0026 で済んでいる。
  入口が増えただけなので、画面の分岐を増やさない。

## 検討した代替案

- **ルームのヘッダーに「…」メニューを新設する**: 上記のとおり中身が 1 つになる。
- **サイドバーの行の右クリック / ホバーのメニュー**: デザインに行のメニューがなく、モバイルで出す場所もない。
- **退出を確認なしで行う**: 非公開は自分で戻れないので、取り消せない操作として確認を挟む（キック・ワークスペースの退出と同じ）。

## 結果（トレードオフ）

- 設定ダイアログが縦に長くなる（非公開でメンバーが多いとき）。メンバーの一覧は既存のまま高さを制限していないので、
  長くなりすぎるならメンバー一覧の側でスクロールさせる。
- 非公開チャンネルの最後のメンバーが退出すると、そのチャンネルは誰にも読めなくなる（admin 以上でも、読めないルームは管理できない。ADR 0011）。
  サーバーは止めていない。説明の文言で重さを伝えるにとどめる。
- 退出の失敗の表示はデザインにない。ほかの操作と同じく、確認を残してコンソールに出す（`docs/ui/README.md` の未解決）。
- `chat/room-settings-dialog.png`（Claude Design 由来）には退出の欄が写っていない。足した部分は実装から撮った
  `chat/room-settings-leave.png` にある。
